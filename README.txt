Maya app
1. Put ALL these files in a GitHub repository (package.json must be at the top level, and the .github folder too).
2. Open the repository > Actions tab > "Build Maya APK" > wait until green.
3. Open the finished run > Artifacts > Maya-APK > download, unzip, install app-debug.apk.
4. Open Maya > Profile > paste your Gemini key > Save.
